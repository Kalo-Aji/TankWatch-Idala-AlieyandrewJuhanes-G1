1. PROJECT OVERVIEW

TankWatch is a Django-based LPG monitoring and usage-tracking system for
members, students, operators, and administrators. Members and students record
their LPG consumption and monitor the tank balance linked to their account.
Administrators can manage accounts and adjust member tank levels for
simulation purposes.

Core feature for this increment: LPG Usage Tracker

The LPG Usage Tracker is the core feature because it records each member's
consumption and updates their remaining gas balance. It brings together
account ownership, tank balance, consumption history, validation, and
role-specific access in one complete workflow.

2.2 Core Feature: LPG Usage Tracker

Description:
Members and students can record LPG consumption in kilograms. A valid
consumption record reduces the remaining amount in that user's 14.20 kg
default tank and appears in their consumption history. Users can read, edit,
and delete their own records; editing or deleting a record reconciles their
tank balance. Administrators can separately view member LPG levels and adjust
a member's simulated tank percentage.

User Roles and Access

Member / Student:
- Create a consumption record.
- View their own tank status, daily usage, and consumption history.
- Edit or delete their own consumption records.
- Cannot access another user's consumption records.

Administrator:
- View member tank levels in the LPG Simulation admin page.
- Adjust a member's tank level from 0% to 100%.
- Does not directly edit member consumption records through the tracker.

Operator:
- Cannot access the member LPG usage tracker.
- Uses the operator dashboard.

User Flow

1. Register or sign in with a Member or Student account.
2. Open the member dashboard and review the current tank level and remaining
   kilograms.
3. Enter a consumption amount in kilograms and submit the form.
4. The system validates the amount, saves the record, subtracts it from the
   tank balance, and displays a success message.
5. Review the saved record in Consumption History.
6. Select Edit to change the amount. The system validates the new amount and
   recalculates the balance.
7. Select Delete and confirm to remove a record and restore its consumed gas,
   up to the tank's capacity.
8. An administrator can separately use LPG Simulation to view or adjust a
   member's tank percentage.

Delete - Yes
UI: Consumption History, Delete action with confirmation.

Database Models

ConsumptionRecord
Key fields: id, amount_kg, created_at, user.
Relationship: ForeignKey to the configured User model. Each record belongs
to the user who created it.

MemberTank
Key fields: id, capacity_kg, remaining_kg, user.
Relationship: OneToOneField to the configured User model. Each user has one
tank.

Validation and Business Rules

1. Consumption amount is required, must be a valid decimal, must be at least
   0.01 kg, and supports up to two decimal places. Invalid input displays a
   field error.
2. Consumption cannot exceed the available tank balance. The server validates
   against the locked, current balance and returns an error instead of saving
   an invalid record.
3. Only authenticated Member and Student roles can access tracker pages.
   Other roles are denied or redirected.
4. Users can edit or delete only their own records. The record lookup checks
   both the record ID and the currently authenticated user.
5. Tank and record updates happen atomically. Editing applies the difference
   between old and new consumption amounts. Deleting restores the record
   amount, without exceeding tank capacity.
6. Admin tank-level adjustment accepts values from 0% through 100%.
